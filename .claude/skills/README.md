# Скиллы

Скиллы ниже скопированы без изменений из [cbrock84/headcount](https://github.com/cbrock84/headcount)
(коммит `98d1c17`, лицензия MIT — см. `LICENSE-headcount`). Изменено только имя: `code-review` → `change-review`, чтобы не конфликтовать со встроенным скиллом Claude Code.

| Скилл | Источник | Зачем здесь |
|---|---|---|
| `systematic-debugging` | technology | Искать корневую причину бага в индикаторе, а не латать симптом |
| `test-driven-development` | technology | Сначала проверка, потом код (для Python-частей, если появятся) |
| `change-review` | technology | Ревью изменений в Pine Script |
| `completion-verification` | technology | Не объявлять задачу готовой без проверки |
| `quantitative-analysis` | data-analytics | Анализ результатов/бэктестов без самообмана (выжившие, множественные сравнения, регрессия к среднему) |
| `ceo-advisor` | executive | Проверка торговой идеи или плана на прочность до внедрения |

Тематических скиллов по трейдингу в headcount нет.
